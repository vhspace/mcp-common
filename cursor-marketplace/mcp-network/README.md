# mcp-network

Read-only MCP server + `network-cli` for querying Together AI network switches
over SSH. The first (and currently only) site is **ORI-TX** — 4 leaf + 2 spine
NVIDIA SN5600 switches running Cumulus Linux 5.15. Every tool is
**non-destructive**.

The MCP tools and the `network-cli` commands are the **same functions**: each is
declared once with `@dual_mode_tool` in `mcp_network.server` and the CLI is
synthesized by `mcp_common.dual_mode.build_cli_from_mcp`, so the two surfaces
never drift.

## MCP server

```bash
uvx --from git+https://github.com/togethercomputer/mcp-common@main#subdirectory=servers/mcp-network mcp-network
```

### Required env vars

SSH credentials are supplied via environment variables named in each site's
inventory JSON (`src/mcp_network/inventory/sites/*.json`). For ORI-TX:

- `ORI_NETWORK_USER` — read-only SSH username
- `ORI_NETWORK_PASSWORD` — read-only SSH password

No credentials are ever stored in the inventory files — only the *names* of the
env vars that hold them.

## CLI: `network-cli`

```bash
uvx --from git+https://github.com/togethercomputer/mcp-common@main#subdirectory=servers/mcp-network network-cli --help
```

Human-readable output by default; pass `--json` / `-j` for machine-parseable
output.

## Tools / commands

All 12 tools are read-only. The optional `site` (`-s/--site`) parameter defaults
to the configured default site (ORI-TX).

| MCP tool | `network-cli` command | Description |
|----------|----------------------|-------------|
| `list_sites` | `sites` | List registered sites, the default site, and aliases |
| `list_switches` | `switches` | List switches in a site (role, model, reachability) |
| `get_system_info` | `system-info` | Hostname, OS version, uptime, health, model |
| `get_port_status` | `port-status` | Port operational state (+ uplink/downlink classification) |
| `get_port_counters` | `port-counters` | Traffic / error / drop / PFC / ECN counters for a port |
| `get_lldp_neighbors` | `lldp` | LLDP neighbor table |
| `get_bgp_neighbors` | `bgp` | BGP neighbor summary (default VRF) |
| `get_mac_table` | `mac-table` | Bridge MAC table (filter by mac/port/vlan) |
| `find_port_for_mac` | `find-mac` | Scan switches for a MAC (direct vs indirect hits) |
| `find_port_for_node` | `find-node` | Resolve a node's NIC MACs via `netbox-cli`, locate on fabric |
| `get_logs` | `logs` | journalctl entries with filters and presets |
| `get_wjh` | `wjh` | What Just Happened — ASIC hardware packet drops |

`find_port_for_node` shells out to `netbox-cli` (must be on `PATH`).

## Development

This server is an independent `uv` project that pins `mcp-common` by release
tag. Mirror CI locally:

```bash
cd servers/mcp-network
uv sync --all-extras
uv run ruff check src/ tests/
uv run ruff format --check src/ tests/
uv run mypy src
uv run pytest -q -m "not integration and not e2e and not slow"
```

## Generated Files — Do Not Edit

`.cursor-plugin/`, `.claude-plugin/`, `.opencode/`, `.openhands/`, `AGENTS.md`,
`opencode.json`, `.mcp.json`, and `hooks/hooks.json` are generated by
`mcp-plugin-gen` from `mcp-plugin.toml`. Edit the canonical sources
(`mcp-plugin.toml`, `skills/*/SKILL.md`, `rules/*.mdc`) and regenerate.
